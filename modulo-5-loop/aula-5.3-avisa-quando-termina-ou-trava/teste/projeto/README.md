# Projeto de teste da aula 5.3

Projeto falso onde a sandbox do validar.py roda os comandos do PDF. Simula o repositório de um
aluno que chegou ao Módulo 5: comando de teste (`npm test`), teste de aceite listado em
`.claude/aceite.txt` e o hook guarda-aceite registrado (aqui um stand-in do da aula 4.2).
